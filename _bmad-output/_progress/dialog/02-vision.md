## Key Insights Captured

1. The primary user is the founder himself — v1 is genuinely "audience of one," not a proxy for a future external user.
2. The core problem is vagueness, not blindness — he already senses overspending; the product's job is to convert that feeling into a specific, trustworthy number.
3. The value moment is a periodic (roughly monthly) glance at category totals — this is a check-in habit, not a dashboard he'll live in.
4. Zero setup friction (manual entry, no bank-linking/SMS permissions) is a deliberate choice, not a limitation to apologize for.
5. There's a secondary, personal motivation running underneath the product goal: proving he can ship something real, solo, start to finish, in a self-imposed short window.
