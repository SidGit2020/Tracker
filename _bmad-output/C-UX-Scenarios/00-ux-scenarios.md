## Scenarios

### [01: Siddi Logs an Expense](01-siddi-logs-an-expense/01-siddi-logs-an-expense.md)
**Persona:** Siddi the Self-Tracker — logs an expense in seconds without breaking flow
**Pages:** Home / Log Screen
**User Value:** The expense is captured in a couple of seconds and the running total updates immediately, so he trusts it registered correctly
**Business Value:** One more day added to the continuous logging streak — the exact signal the day-14 metric measures

---

### [02: Siddi Reviews the Month](02-siddi-reviews-the-month/02-siddi-reviews-the-month.md)
**Persona:** Siddi the Self-Tracker — wants a specific, trustworthy number that replaces the vague feeling
**Pages:** Monthly Category Breakdown
**User Value:** Confirms exactly how much he spent in each category this month, replacing the nagging feeling with a specific trustworthy number
**Business Value:** Validates the "trust the number" prerequisite (zero discrepancy, spot-check confirmed) that keeps the day-14+ habit alive
